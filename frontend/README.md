# Vue 3 + TypeScript + Vite

这个模板用于帮助你基于 Vite 开始开发 Vue 3 + TypeScript 项目。模板使用 Vue 3 的 `<script setup>` 单文件组件语法，更多信息可查看 [script setup 文档](https://v3.vuejs.org/api/sfc-script-setup.html#sfc-script-setup)。

关于推荐的项目配置和 IDE 支持，可继续阅读 [Vue 文档中的 TypeScript 指南](https://vuejs.org/guide/typescript/overview.html#project-setup)。
